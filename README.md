Banking Performance Dashboard

Objective
Analyze Deutsche Bank’s financial performance to deliver strategic insights for banking stakeholders.

Dataset
Kaggle: DeutscheBank Financial Performance

Tools
Power BI (Power Query, DAX, Visuals)

Key Features
Data Cleaning: Processed data in Power Query, handling nulls and ensuring compliance-ready datasets.
Data Modeling: Designed a 1-to-many star schema with a Date dimension for robust analysis.
DAX Measures: Developed measures including Total Revenue, Total Expenses, Profit Margin, YoY Revenue Growth, and Operating Efficiency.
Visuals: Created interactive KPI cards, Line/Bar/Area Charts, a Donut Chart for Revenue/Expenses/Net Income breakdown, and a Q&A visual for queries like “Expenses in 2023,” styled in a banking theme.

Interactivity: Enabled cross-filtering, tooltips, drill-downs, bookmarks, and natural language Q&A for user-friendly exploration.
Insights: Identified high-profit years, analyzed cost structures, and provided recommendations for expense optimization.
